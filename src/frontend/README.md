# GeoTracker frontend

Next.js App Router UI for the Iozera GeoTracker prototype.

**Full project documentation** (features, API, setup, admin routes): see the [repository README](../../README.md).

## Run locally

```bash
npm install
# .env.local: NEXT_PUBLIC_API_URL, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY
npm run dev
```

Backend must be running at `NEXT_PUBLIC_API_URL` (default `http://localhost:8000`).
